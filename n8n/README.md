# n8n Workflow

This folder contains an example workflow for [n8n](https://n8n.io/).

The workflow `google-sheets-to-drive-workflow.json` demonstrates how to:

1. Read data from a Google Sheets document.
2. Process or transform the rows in a Function node.
3. Upload the transformed data as a file to Google Drive.

Import the JSON file into n8n to view and run the workflow. Replace the `sheetId` and other parameters with your own information.
